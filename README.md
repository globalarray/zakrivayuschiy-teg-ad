# Закрывающий тег

Адаптивная страница учебного путешествия: восемь карточек, CSS-фильтры, анимированные SVG-сердца и модальное окно.

## Запуск

Откройте `index.html` через локальный HTTP-сервер, например `python3 -m http.server 8000`.

Изображение фургона и фавиконки нарисованы специально для проекта. Используются локальные Inter Variable и PressStart2P.
